This page lists the work that the Eclipse Atesor™ sources on `main` describe as planned. Nothing on this page is in a release, and the sources give no dates for it. For what Atesor can do today, see [Limitations](/atesor/docs/introduction/limitations/).

## Where does the roadmap come from?

The [source repository](https://github.com/eclipse-atesor/atesor) has no roadmap file. On `main`, only `README.md` states a plan.

## Which items are planned?

| Item | State on `main` | Source |
| --- | --- | --- |
| More build systems | The README lists Make, CMake, Meson, autotools, Cargo and Go modules, and says that more build systems will follow. | `README.md` |

For the build systems that Atesor supports, see [Build systems](/atesor/docs/reference/build-systems/).

Performance mode and the Anthropic provider are finished features, not plans. See [Performance mode](/atesor/docs/guides/optimize/) and [Configure the LLM](/atesor/docs/getting-started/configure-llm/). [Releases](/atesor/docs/project/releases/) lists the features that are on `main` but not in `v0.2.0`.

## How do you follow the roadmap?

- Read the commits on `main` in the [source repository](https://github.com/eclipse-atesor/atesor).
- Watch the [releases](https://github.com/eclipse-atesor/atesor/releases). See [Releases](/atesor/docs/project/releases/) for the release types.
- Ask on the [developer mailing list](https://accounts.eclipse.org/mailing-list/atesor-dev) or in a [GitHub issue](https://github.com/eclipse-atesor/atesor/issues).
