This page holds every logo file of Eclipse Atesor™, with what each file is for. Use these files when you write about Atesor, give a talk, or link to the project. The story behind the name and the mark is on [About the name](/atesor/docs/project/name/).

Each file link on this page opens the file itself. Use the files as they are.

## The mark

The mark is a stone with one cut corner. One line inside it starts at an open ring, reverses on three rows, and ends at a solid pad: source code in, a native riscv64 binary out.

## How do I use the logo?

- Keep clear space on all sides, at least the size of the cut corner.
- Use the full mark at 24 pixels or larger. Below 24 pixels, use the favicon.
- Use the dark-background files on dark backgrounds.
- Do not rotate, stretch, outline or shade the mark.
- Do not change its colours, other than to the one-colour file.
- Do not put the mark on photos or busy patterns.
- Do not set "atesor" in a font as a logo. Use the wordmark file.

## How do I write the name?

- The first time on a page, write **Eclipse Atesor™**. After that, write **Atesor**.
- Do not write "ATESOR" or "Atesor AI".
- The command and package name is `atesor-ai`, in code font.
- The tagline is "From source to verified riscv64."
