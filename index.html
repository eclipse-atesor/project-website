Eclipse Atesor™

From source to verified riscv64.

An open-source agentic framework that ports software to RISC-V. Give it a repository URL. It builds the package natively on riscv64, repairs what breaks, checks every binary, and writes a recipe that anyone can replay.

How a port runs

From source code to a verified RISC-V build, in three steps.

  1. 1Point it at source code

    Give it a link to the Git repository.

  2. 2It builds and tests on RISC-V

    On an emulated or a real riscv64 machine. It fixes what breaks on the way.

  3. 3It verifies the result

    It checks that every binary is real riscv64 code, and writes the steps into a recipe.

Read more about how it works

Every port ends in a recipe

Each port gives back a Markdown recipe: the steps that built the package. A person or a CI job can replay it.

  • Verified binariesEvery output is riscv64.
  • A recipeSteps a CI job can replay.
  • The patchesEach fix, as a .patch file.
  • A full logEvery model call and its cost.

Install

You need Docker with riscv64 emulation and one LLM API key: Gemini, OpenAI, OpenRouter or Anthropic.

Debian or Ubuntu package

Download atesor-ai_0.2.0_amd64.deb from the v0.2.0 release.

sudo apt-get install ./atesor-ai_0.2.0_amd64.deb
mkdir -p ~/.config/atesor-ai
cp /opt/atesor-ai/app/.env-example ~/.config/atesor-ai/.env
atesor-ai --setup-only
atesor-ai --repo https://github.com/madler/zlib --force

From source

Python 3.10 or later, in a virtual environment.

git clone https://github.com/eclipse-atesor/atesor
cd atesor && pip install -r requirements.txt
cp .env-example .env
python3 main.py --setup-only
python3 main.py --repo https://github.com/madler/zlib --force
